# Ray+IR 교사 2769 / 3906 MuJoCo 배포 실험 정리 (2026-10-16)

**모델 (계보 이름)**
- `d_v3.6.21_b1_18_2769`: Ray+IR 2769 ← GAST v2.1 2000 ← 21068 ← 17206 ← RBQ 배포 blind b1_18
- `dwb38000_3906`: Ray+IR 3906 ← DWB-38000 (우리 ARM4 blind, 처음부터 학습)

**코스와 조건**
- 코스: `gap_stairs_force4`. 갭 5–30 cm → 4 m 도움닫기 → 20 cm 계단 20단(올라갔다 내려감) → 25 cm 계단
- 주행 조건: vx 1.0, noise on, 짐 6 kg
- 외력: 고관절 핸들에 각 2 s
  - 오르막에서 당김 200 N @ x 15.3
  - 오르막에서 밂 200 N @ x 18.0
  - 내리막에서 당김 200 N @ x 23.3
  - 내리막에서 밂 100 N @ x 26.0

**센서 모드 (지도는 sidecar가 만들어 UDP로 Pilot에 보냄)**
- `lidar`: LiDAR → v25or 지도, IR 0 (374 입력)
- `lidar_ir`: 같은 지도 + IR 대리값 (561 입력)
- `depth_ir`: 배 아래 카메라 4대의 depth(sidecar 레이캐스트) → camfilter136 → v25or + IR

**시행 횟수**
- 모드별로 LiDAR 3회, LiDAR+IR 3회, Depth+IR 4회
- 1차 20회 + v2 20회
- oracle은 교사당 3회. 정답 높이 지도를 쓰지만, noise on이므로 합성 지형 노이즈와 blackout이 섞여 있음

## 판정 정의
- **기존 판정 (`summary.md`, 출처 보존용)**: final_x ≥ 40.9이고, 각 외력 구간 안에서 기울기 60°를 넘지 않으면 PASS
- **사건 분류 (`evaluation/force4_classify.py`, 이 문서의 표)**: 전체 기록에서 처음 일어난 사건으로 분류
  - FALL: 기울기 70° 초과. 구간은 넘어지기 직전의 최대 x로 정함
  - GAP-PIT: 갭 구간에서 몸통 높이 z < 0.3 m가 1 s 넘게 지속
  - 둘 다 없으면 FINISH 또는 STOP
- 처음에는 최종 위치(final_x)로 넘어진 곳을 보고했으나 틀렸음. 로봇은 x 15.3의 당김에 넘어진 뒤 계단 아래 x ≈ 12까지 굴러 내려옴.

## 해석 (UPDATE139 검토 의견과 oracle 결과)
1. **실패 대부분은 외력 구간이다.** 6 kg을 실은 채 계단에서 200 N으로 당기면 정답 지형을 줘도 넘어진다(2000, 2769, 26123 oracle 모두). 이 코스는 센서 검증이 아니라 외력 강인성 시험이다.
2. **갭에 빠지는 것도 oracle에서 일어난다.** 2769는 1/3, 3906은 2/3이다. 그러므로 Isaac 99% → MuJoCo 갭 실패는 센서보다는 정책의 MuJoCo 이전(sim2sim) 또는 oracle 지형 노이즈 쪽 문제일 가능성이 크다.
   - 2769 센서의 갭 실패 9/20은 oracle 1/3보다 많아 보이지만, oracle 표본이 작아 단정하지 않는다.
3. **정하지 않은 것**: 교사 순위, pit 인코딩 수정, Depth 5 Hz, 접촉·구동기 조정. 모두 보류한다.
