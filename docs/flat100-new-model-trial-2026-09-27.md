# 새 모델 100m 평지 직진 시험 — 2026-09-27

## 결과

teacher3879/student20000 모델이 약 100.01m를 408.74초(6분 49초)에
연속 보행했다. 목표 x=100m에 도달했으며 안전 중단, 넘어짐, 영상 timeout
TRIP은 없었다. 종료 후 STAND(FSM6), 속도 명령 0, 소유권 3으로 확인했다.
이 결과는 단일 시뮬레이션 시험이며 실기 안전성이나 반복 신뢰도를 입증하지 않는다.

## 조건 및 보존

- 별도 `docker/terrain/vrl_progression/flat_100m.xml`: x=-4..102m 연속 지면,
  실제 시험 구간 x=0..100m, 폭 6m, z=0, friction=0.8/0.8/0.8.
- 기존 갭/계단 XML과 사용자 변경은 보존했다. 로봇 모델/6kg payload도 유지했다.
- 실제 MuJoCo 렌더 IR+Depth, 기존 동기화 방식 사용. 영상 주입 없음.
  IR은 렌더 영상의 grayscale proxy이지 물리 IR 센서가 아니다.
- 원래 Pilot PID502520, 같은 새 정책, 같은 gains/history/전처리 사용.
- MuJoCo만 ESTOP에서 기존 프로세스5038 종료 후 새 XML로 시작했다.
  새 컨테이너 내부 PID11315. Motion 및 학습 PID298486은 유지했다.
- 전진 명령 0.18m/s; 기존 +X/중앙선 yaw 보정 사용(max 0.25rad/s).
  따라서 완전한 무보정 직진 시험은 아니다.
- 최대 540초. 기존 안전 기준 유지: 관절 속도20rad/s, roll/pitch0.4rad,
  |y|0.5m, body z0.30..1.40m, 위치 표본 age0.75초.
- `tools/sim_trial.py`는 위치 감시가 있는 시험의 최대 시간을600초로만 확대했다.
  일반 시험 제한과 안전 임계값은 변경하지 않았다.

## 측정치

50Hz 텔레메트리와 10Hz 실제 시뮬레이션 위치를 기록했다. WALK/FSM7 및
정책 소유권20 표본을 분석했다. 순간 피크는 표본 사이에서 누락될 수 있다.

| 항목 | 전체 WALK | 시작10초 제외 |
|---|---:|---:|
| 최대 절대 roll | 1.13° | 0.73° |
| 최대 절대 pitch | 5.72° | 4.68° |
| roll 표준편차 | 0.185° | 0.179° |
| pitch 표준편차 | 0.502° | 0.470° |
| 최대 절대 관절 속도 | 9.57rad/s | 8.83rad/s |
| 최대 절대 관절 토크 | 81.37Nm | 45.67Nm |
| 몸통 높이 범위 | 0.461..0.512m | 0.461..0.490m |
| 최대 중앙선 이탈 | 5.42cm | 5.42cm |

전체 속도 피크는 t=5.184초, FR knee(index8), -9.573rad/s였다.
토크 피크는 WALK 진입 t=1.204초, RR knee(index2), +81.374Nm였다.
진입 토크가 정상 보행보다 크므로 '급격한 동작이 전혀 없다'고 결론 내리지 않는다.

후반20m 구간의 관절 속도 최대는8.83rad/s, roll0.73°/pitch4.07°였다.
장거리 후반에 자세 흔들림이 증가해 붕괴하는 현상은 이 시험에서 관측되지 않았다.
100Hz 정책 로그의 최대 목표각 step은0.117893rad(약6.75°)/tick였다.
이는 흔들림이 작더라도 action이 완전히 매끄럽지는 않다는 뜻이다.
50Hz 관측 목표각 step 최대0.2093rad는10ms 정책 step과 직접 비교하지 않는다.

평균 실제 전진 속도는0.2447m/s로 0.18m/s 명령보다 약36% 빠르다.
평지 연속 이동은 성공했지만 속도 명령 추종은 개선 여지가 있다.
영상 age 최대872ms, Held 비율9.62%, timeout TRIP 없음. 지연이 없었다는 뜻은 아니다.
이전 갭/계단 코스와 형상 및 영상 내용이 다르므로 결과 차이를 모델이나
지연 하나의 원인으로 단정하지 않는다.
