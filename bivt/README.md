# BIVT — Blind-Initialized Visual Teacher

교사 출처 분류다. Render v1/v2, Ray는 교사 학습 변형이며 RVLD/GAVD 학생 방식과 별도 축이다.

BIVT-Render v1의 `model_1299.pt`는 학습 리포
`gd_lab_vrl/checkpoints/teachers/bivt/render_v1_final_20260930/teacher/`에 수신되어 있다.
이 교사에 연결한 카메라 학생/배포 ONNX 쌍은 아직 이 리포에 없다.
따라서 현재 디렉토리는 연결 상태 안내만 제공하며, 실행기나 배포 완료를 가장하지 않는다.
