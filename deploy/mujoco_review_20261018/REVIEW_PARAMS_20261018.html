MuJoCo 조이스틱 리뷰 실행 변수 deploy/mujoco_review_20261018 · 2026-10-18

센서 경로 = 로봇 경로: 하부 depth 카메라 4대 → camfilter136 → v25or 지도 + IR → GAST 교사. 계단 4지점 자동 외력, odom(pose) 오차 주입 지원. 조이스틱(CAMEL-Console)으로 직접 주행하고, 외력은 지정 위치에서 자동으로 걸린다.

사용법

cd ~/gd_project/gd_rbq10_deploy_vrl/deploy/mujoco_review_20261018

bash 2_orig_3906/run_sim.sh [코스]      # 시작 (기본 코스 force4)
bash 2_orig_3906/run_sim.sh --check     # 정적 검사만
bash 2_orig_3906/run_sim.sh stop        # 이 모델 정리
bash _lib.sh stop                       # 네 모델 폴더 모두 정리 (stop_all.sh)
주의시뮬레이터는 한 번에 하나만 돈다. 모델을 바꾸기 전에 반드시 stop(또는 bash _lib.sh stop)을 실행한다. 이미 sidecar나 Pilot이 떠 있으면 시작을 거부한다.

수치는 실기 측정 전 가정치다. 오차 pose는 매퍼(지도 쌓기)와 Pilot 지형 기억 정렬에 똑같이 쓰인다(실기 /odom 구조와 같음). 정지 중에는 drift가 누적되지 않는다(이동 0.05 m/s 또는 회전 0.05 rad/s 초과 시만). z·roll·pitch 오차는 없다.

예시

bash 2_orig_3906/run_sim.sh                                      # odom P2, 6 kg, 외력 150 N × 2 s

POSE_ERR=P3 bash 2_orig_3906/run_sim.sh                          # 큰 odom 오차

RBQ_SIM_OBS_NOISE=0 POSE_ERR=off bash 2_orig_3906/run_sim.sh     # 노이즈 모두 끔

bash 2_orig_3906/run_sim.sh stop
